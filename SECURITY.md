# Security

## Reporting a vulnerability

If you find a security problem, we ask, but do not require, that you report it privately rather than in a public issue,
discussion or pull request. That gives us a chance to fix it before it is widely known, which protects everyone who
runs Agenthix.

To report it privately, use this repository's **Security** tab, with **Report a vulnerability**. Say what is affected,
how to reproduce it, and what someone could do with it.

Agenthix is in early access and maintained by a small team with limited time, so we cannot promise a response time or a
fix date. Early users who help are what make this project work, and we are grateful for every report.

## Supported versions

Agenthix has not had its first release yet. Once it has, fixes go into the latest release.
