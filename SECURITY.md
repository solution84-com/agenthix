# Security

## Reporting a vulnerability

Please do not report a security problem in a public issue, discussion or pull request.

Report it privately through this repository's **Security** tab, with **Report a vulnerability**. Say what is affected,
how to reproduce it, and what someone could do with it. You will get a reply, and we will agree with you when the
problem and its fix are made public.

## Supported versions

Agenthix has not had its first release yet. Once it has, fixes go into the latest release.
