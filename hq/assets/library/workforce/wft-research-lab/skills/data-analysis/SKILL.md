# Data Analysis

Analysis is only as good as the assumptions behind it.

## Before analysis
1. Understand the question — what decision will this analysis inform?
2. Audit the data — missing values, outliers, schema inconsistencies
3. State your assumptions explicitly before running queries

## During analysis
- Keep raw data separate from derived data
- Version your queries — track what you ran and when
- Document each transformation step

## Visualisations
- Choose the chart type that matches the claim (trend → line, comparison → bar, distribution → histogram)
- Label axes with units
- State the data source and date range
- Highlight the finding — don't make the reader hunt for it

## Deliverables
- The finding: one clear sentence
- The evidence: chart or table
- The caveat: what this analysis can't tell us
