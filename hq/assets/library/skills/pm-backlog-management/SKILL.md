# Backlog Management

A well-managed backlog means the team always has clear, actionable work.

## Task quality checklist
- [ ] Title is a clear action statement
- [ ] Acceptance criteria listed
- [ ] Dependencies noted
- [ ] Priority set

## Grooming
- Review the top 10 items weekly
- Break epics into single-session tasks
- Remove stale tasks promptly
