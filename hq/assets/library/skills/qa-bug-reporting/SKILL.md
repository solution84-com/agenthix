# Bug Reporting

Every bug report must be reproducible and actionable.

## Required fields
- **Title**: short description of the failure
- **Severity**: P1 (blocker), P2 (major), P3 (minor), P4 (cosmetic)
- **Repro steps**: exact numbered steps
- **Expected result**: what should happen
- **Actual result**: what actually happened
- **Evidence**: screenshot or log

## Severity guidelines
- P1: data loss, security issue, core feature broken
- P2: important feature broken, no workaround
- P3: feature degraded, workaround exists
- P4: visual issue or minor friction
