# Sprint Planning

A sprint plan commits the team to a clear, achievable scope.

## Before the sprint
1. Review the top backlog items with the team
2. Confirm each task has acceptance criteria
3. Estimate effort (small / medium / large)
4. Pick tasks that fit the sprint capacity

## Sprint goal
- Write one sentence that captures what the sprint delivers
- Every task in the sprint should contribute to this goal

## During the sprint
- Daily standup: what's done, what's in progress, any blockers
- Scope changes require explicit re-planning — no silent additions

## At sprint end
- Demo completed work
- Move incomplete tasks back to backlog with a note explaining why
- Capture velocity for future planning
