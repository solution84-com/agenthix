Masking, worked

Before anything leaves the site, the site replaces every secret value, in each of these forms, with ***. GitHub Actions masks its logs the same way. Every secret of the place, not only the run's own: all the project's (or person's) secrets, and every token minted for it that hasn't expired. So a value one run left behind is still masked when a later run, or another workflow, prints it. hq sends the site only what it needs to find them (their masked forms, or keyed hashes), never extra values in plain.

  • base64 at every alignment: a value inside a longer base64 string (an Authorization: Basic … header) lands at one of three offsets, so all three are masked. Hex in both cases.
  • Across chunks: live output is held back by the length of the longest secret before it's sent, so a value split between two chunks is still found.
  • File secrets line by line: a 48 KB file (a private key) is matched by each of its lines too, so printing part of it is masked.
Masking catches accidents, not intent. A workflow written to leak can encode a value so that no mask finds it. What stops that is the review: the plain checks flag a secret used near output, and the reviewer agent and the person read the code before it can run (board 5).

Files the run changed

A workflow could write a secret into a file for the agent to read later. The run works on a snapshot the agent can't see (board 6), so nothing reaches the agent's workspace until it's been checked. When the run ends, the site checks every file the run created or changed in the snapshot, and everything in /run/out, for the same forms as the output.

  • By content: the site compares the files themselves against the start, not their modification times and sizes, which a program can set back.
  • Git's own files too: a value committed by a step is stored compressed in .git/objects, where none of the forms above would find it. The site reads the run's new git objects decompressed and checks those as well.
  • Nothing found: the changes are written back to the agent's workspace.
  • A value found: the run fails and none of its changes are written back. The person sees which file and which secret. The agent sees only "the run left a secret in a file, so its changes were dropped".
