The starter workflows are proposed the moment a repository is connected, so the person who connected it, if they're an administrator, approves them in the same sitting. set-github-secrets is proposed only when a GitHub workflow needs a secret (G3).

Why

  • P1 came from finding out too late. Every check that can be made before creating is made before creating.
  • Connecting is the natural moment to approve push, pull and pull requests: until then, agents can work on the code but not share it, and the screen says so.
