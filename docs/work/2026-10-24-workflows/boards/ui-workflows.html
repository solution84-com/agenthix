Run
  1. Needs you comes first, and only for the project's administrators; others see "Waiting for an administrator".
  2. Each row: name, description, steps, the secret variables it uses (plain ones are on its page), and its last run.
  3. The switch turns it on or off, for administrators; others see the state only. Off rows are dimmed and Run is unavailable.
  4. Run asks for the parameters, if it has any (U3), then opens the run (U5).
  5. A click on a row opens the workflow (U3).

Why

  • Itemised so a person can always see everything that can run with the project's secrets, without searching conversations.
  • The switch on the row, as on GitHub's workflow list and n8n's, because turning something off quickly is the moment that matters.
