Settings › Sign-in — the Agenthix account

Spec part D, second bullet; part C2. A member sees what Cloud gives them and can ask for it. The section shows the person's Agenthix account in every state; when HQ is not connected, Ask a fleet admin to turn it on, once per person.

Today

  1. Settings is one page of the person's own sections. The last, Sign-in, has one row — Password · Set · Change — and the Sign out button.
  2. Nothing about an Agenthix account, and no way to ask for one.
Before
Password and Sign out.
After
A first row, Agenthix account, above Password. Connected and linked: Linked, what it gives, and Unlink. Connected, not linked: Link your Agenthix account ↗. Not connected: what it would give, and Ask a fleet admin to turn it on; once pressed, You asked and no button, for good. A person who signs in only with Cloud sees Password · Not set · Set a password, and cannot unlink until they set one.
Why
Spec D: members can see what Cloud gives and ask for it, once each, and the count reaches fleet admins. Linking happens here, after signing in as oneself (C2). Unlinking without a password would lock the person out, so it waits for one.

Built from · hq/src/settings/pages/SignInSection.tsx gains a CloudAccountRow (new file beside it), drawn with the existing SettingsRow, Button variant="secondary" and StatePill from @agenthix/ui/primitives. Data: a new query, say getMyCloudSignIn, answering {{ connected, linked: boolean, hasPassword: boolean, askedAt: string | null }} — read from the CloudConnection row and the person's own record, never by calling Cloud. Actions: linkCloudAccount (starts the OIDC request, returns to /settings), unlinkCloudAccount (refused without a password), askForCloudSignIn (stores askedAt on the person once; a second call changes nothing). The Fleet Console's count reads the number of people with askedAt set (see the Cloud section board).

Open, decided conservatively for the owner: Whether You asked should ever reset — for example when HQ disconnects from Cloud after being connected. Drawn as once for good, as the spec says once per person.
