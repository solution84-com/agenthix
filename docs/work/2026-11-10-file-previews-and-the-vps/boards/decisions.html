D2 · A JSON file too big to show whole · revised

The agent exported 7.7 MB of customers as JSON (about 30,000 records). You open it to check the records look right.

The limits today, and what 5 MB means. Text, code and Markdown show their first 1 MB (a log: about 15,000 lines). JSON is drawn as a tree up to 5 MB; past that it shows its first 5 MB as raw text. Measured on the sample: 5 MB is 19,600 records, which is about 600,000 lines once formatted. 1 MB is 3,900 records, about 120,000 lines. Neither is something a person reads line by line.
Proposed · first 1 MB, records folded

The same 1 MB limit as every other text file. Shown as the JSON tree, with each record folded to one line: 3,900 lines to scan, and any record opens to check its values. Only whole records are shown, never half of one.

D4 · A file that's linked to another file · revised wording

Rarely, an agent leaves a file that is really a second name for another file somewhere else on the machine (a "hard link"). Agenthix can't tell where that other file is, or whether you're allowed to see it, so it never opens these. You click one.
