Notices: exports, erases and remote sessions

§4: every remote Fleet Console session, export and erase is announced to all fleet admins and organisation admins. §15: erase keeps a final backup for a 30-day grace period.

What this is

  • Fleet admins see them in the Fleet Console under Notices (the count in the menu), with a way to the record in Activity.
  • Organisation admins see them in hq's Notifications panel, in hq's look. They say who did it, in plain words, and who to ask — never a link into the Fleet Console, which an organisation admin may not be able to reach and has no role in.
  • Which notices reach organisation admins, as §4 says: every remote session, every export and every erase (and the turning on of remote access, and every grant or removal of the fleet admin role). Nothing else from the Fleet Console goes to hq: a machine's condition, backups, backup locations and upgrades stay with fleet admins.
  • Setting a backup location for a site is announced to every fleet admin only (§6): who set it, for which site, and that its key was shown once to them. It does not go to hq. Not drawn in hq's panel.
  • A person who is both sees each notice in both places.
  • The role being given or removed is announced to every fleet admin and every organisation admin, whether a fleet admin did it in the Fleet Console or a machine admin at the command line. hq shows it in plain words and never links into the Fleet Console.
  • Remote access is announced when it is turned on (“remote access is on until 16:00”) and again for each session; drawn here is the session notice.

Today

hq's Notifications panel exists and already carries notices to organisation admins (agents set to Bypassed, for example). These join them as information, not as something that needs the person. The Fleet Console has nothing yet.
