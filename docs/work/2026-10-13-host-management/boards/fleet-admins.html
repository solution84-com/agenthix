The fleet admin role

§1 and §7: the Fleet Console has no accounts of its own. Fleet admin is a role on an hq account. The first account holds it from the install; after that it is granted in the Fleet Console or by a command on hq's machine.

What this is

  • The first account holds both roles. The install prints one link. The person who opens it creates the account in hq, and it is an organisation admin and a fleet admin. There is no separate invitation for the Fleet Console.
  • Granting the role to an existing hq account: a fleet admin does it in the Fleet Console (Fleet admins tab, Give the role to…, page 3), or a machine admin of hq's machine runs agenthix hq fleet-admin <user>. hq refuses a grant from anyone else; an organisation admin cannot give it (page 3 and hq's own page show this). Every grant and removal is announced (page 6).
  • Recovering it when no fleet admin is left: the same command, agenthix hq fleet-admin <user>, on hq's machine.
  • The authenticator code is for remote sign-in only. It is set up from a session on the Fleet Console's machine or through an SSH tunnel, never from a remote session. A lost code is reset with agenthix console reset-code <user> on that machine.

Today

Only hq's version exists: ./agenthix invite-admin prints hq's first-admin link, or, when every organisation admin has gone, an invitation marked as from hq's machine. The install already prints one link; what changes is that the account it makes also holds the fleet admin role, and the Fleet Console's own invite-admin goes away.

When nobody holds the role

If every account that held the fleet admin role has lost it (an account deleted in hq, for example), the sign-in page cannot help anyone. The machine admin recovers it from the command line; hq checks the account exists, and the Fleet Console and hq announce it.

Next step: on hq-box, a machine admin runs agenthix hq fleet-admin <username> for the account that should hold it.

Resets the code and the recovery codes of that account on this machine. Their HQ password is not touched, and what they did stays recorded against them.

Avery Chen's authenticator code and recovery codes are cleared.
They set up a new code the next time they sign in on this machine
or through an SSH tunnel. Remote sign-in works again after that.
Every fleet admin has been told.
