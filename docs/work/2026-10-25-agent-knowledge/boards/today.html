1 · Today: how agents reach knowledge

Read from the code on main (68bab23b). Everything on this board is today; nothing is proposed.

What exists, numbered

Before · today

1The lead

The agent as it talks in a conversation, run in hq by direct model calls. Has recall, remember, forget, used_memory, start_work.

Knowledge: recall with a query also searches the conversation's place's knowledge (leadMemoryTools.ts:90-130). It cannot write knowledge.

2A worker

A run on the site, in the agent container (Claude Code or OpenCode). Its only instruction channel is the prompt (settingSources: []).

Knowledge: the place's knowledge/ folder as plain files, inside one bind of the whole place folder, writable whenever the run has any write tool (containerPrep.ts:45). No knowledge tool; recall here is memory only.

3The knowledge folder

<place>/knowledge/ on the site, beside files/ and artefacts/, for a project or a person. The prompt says: read INDEX.md first, edit only when asked (promptSectionText.ts:17).

Nothing fixes how an INDEX.md line is written. hq's parser guesses at the shapes agents write; tags are never stored (knowledgeIndex.ts).

4Site search

location.searchKnowledge: word matching over the files, INDEX.md hits first, at most 400 files and 24 lines back (knowledgeSearch.ts). Used only by the lead's recall.

5The Knowledge tool

In the Files group of a project and of Your space. Lists topics, searches, filters by tag (always empty), opens a topic. Edit is a placeholder; there is no delete (KnowledgeTool.tsx, FileOpened.tsx:26).

6Memory, kept apart

Rows in hq (MemoryItem), three scopes, with embeddings and outcomes. Has its own screens: Settings › Memory, a project's Memory tool. Not knowledge, and stays as it is.

7Platform package

Built by hq at boot from hq/assets/platform/skills and staged into every run as skills. The folder is empty. Nothing about Agenthix itself reaches an agent beyond a few lines of instructions.

bThe index is a free-text file that rests on a prompt line (3); tags have nowhere to live.Topics listed with guessed titles; the Tag filter is always empty.
