From inside a project

After · proposed

A project's Knowledge tool shows its own pages. Search there has a switch, This project · Organisation · Both, defaulting to Both, with each result marked by where it is from. Opening an organisation page from a project opens it in the organisation's Knowledge, read-only unless the person is an organisation admin.

Why

  • One kind of knowledge per level, one tool: the organisation's, a project's and a person's look and work the same, so nothing new to learn.
  • Admins change it: it is read by every agent in every project, so a change reaches everyone at once.
  • Search across both from a project, because a project's way of working usually starts from the organisation's.
