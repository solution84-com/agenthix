  1. Title, description, tags and properties are fields, so a person never writes front matter; Save writes the page with it.
  2. Save sends the page through the gate: the same checks as an agent's change. A problem is shown on its field ("Description is missing").

When someone changed it meanwhile

After · proposed
Changed while you were editing. Kernel saved this page 1 minute ago. Your text is kept here: See their change · Save mine over it

The gate refused the save (board 4, G2). "Save mine over it" saves again from the new version; theirs stays in History.

Why

  • A guide page: long, detailed pages need their headings beside them.
  • Properties as fields: a team's own structure (a decision's status) without the platform knowing what it means.
  • One gate for people and agents: the same checks, the same history, whoever saves.
