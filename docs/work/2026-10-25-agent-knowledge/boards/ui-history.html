RestoreDelete permanently

Restore puts the page back at its path, or beside it if a page has taken the path since. Each place's versions are capped at 200 MB; the oldest go first.

Why

  • Agents change shared notes; people need to see what changed and undo it without asking anyone.
  • Restore makes a new version, as document tools do, so nothing is ever lost by restoring.
  • 30 days, the usual length of a recycle bin; the last 20 versions are kept beyond it so an old, rarely changed page still has a past.
