Why
  1. Only true facts. Today two of the three pills are fixed values, so the strip says "ONLINE" when nothing is running
  2. HQ and every site in one glance. Today HQ's facts, each site's health and the database check sit on three different pages
  3. HQ gets a health of its own: how long it has been running and whether its scheduler ticks, the two things nobody can see today
  4. No refresh button to remember. Health updates by itself; Check again is for "ask now"
  5. Nothing useful to an attacker in public. A public version number tells them which known flaws to try (question 90)
