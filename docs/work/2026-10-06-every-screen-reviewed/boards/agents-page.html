Agents — using an agent

This board is using an agent. Managing one — creating it, changing who it is, assigning it — is under Organisation, on its own board Organisation — Agents. Agents in the navigation lists the organisation's agents. An agent opens as a place, like a project: your conversations with it on the left, its tools on the right — a view of the agent across every project in the organisation, as the person looking sees it: their conversations, what needs them, their usage, their own settings for it. The project's Agents tool (board Agents) is the same agent seen from one project, so both use the same sections and the same words.
