Where we are

Agreed

  • Same bar and four layouts as the conversation: breadcrumb and layout control above both panes (Conversation, Side by side, Tool focus, Tool only); here "Conversation" means the list.
  • "Chat" is the person's personal space: today's personal project and today's global chat are one place. "My tasks" leaves the sidebar — its tasks are the Tasks tool here.
  • Same design as a project: conversations list, conversation, tools beside it, four layouts.
  • Any agent in the organisation can be talked to here; a project's conversations stay with that project's agents.
  • Files are the person's own storage — the same storage personal tasks and today's chats already use — on one site, fixed the first time it is used, shown as Site like a project's; hidden until the storage has a site.
  • Tools: Tasks, Boards · Runs, Automation, with Run all / Stop all · Files, Workspaces (a person can own workspaces). No Agents, People or Settings.
  • Questions spanning projects are not possible yet: projects can sit on different sites. Future work, with delivering knowledge across sites.
  • Project conversations do not appear here; they live in their project.

  1. None — agreed.
