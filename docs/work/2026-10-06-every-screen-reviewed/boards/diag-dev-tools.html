Choice A / B · question 95: today's developer tools
A · chosen

Gone from the product

The Debug page and all its tools are removed. What an admin needs is on these boards; a developer reads logs and runs the test suites.

B · not chosen

Kept only in development mode

A Developer section at the foot of Logs and diagnostics, shown only when HQ runs in development (wasp start), never in a built image: raw run rows, and clearing your own run records. Code only some installs run breaks unnoticed, and the Runs screen already shows the same runs.

Why
  1. Nothing in a release that only a developer should press (question 95)
  2. Talking to an agent is the check. A conversation shows that a run works on its site; Health shows connected, Docker, disk and run slots without running anything (question 96)
  3. No one-click deletion of history. Reset History removed usage and tool call records for good; deleting belongs to deleting a conversation or erasing a person
