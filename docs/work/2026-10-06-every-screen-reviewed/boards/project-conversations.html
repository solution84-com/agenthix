Where we are

Agreed

  • Same bar and four layouts as the conversation: breadcrumb and layout control above both panes (Conversation, Side by side, Tool focus, Tool only); here "Conversation" means the list.
  • Redesign first. A new feature comes in only when the design needs it and it is easy; anything with a large architectural consequence is deferred.
  • Conversation first. The project opens on the person's conversations; the composer is always there; tools sit beside it, not in a tab bar.
  • Right panel = facts + tools, one surface with sections (no cards), quiet, not a dashboard: lead, site, default agent, product, access. No status.
  • Light by default, dark available.
  • Each row shows the agent's avatar, the agent's name and the title. Filter by agent.
  • Who answers: the project's default agent — usually its project manager — with a picker for another.
  • Back to Projects: breadcrumb on desktop, ‹ on mobile, ▾ on the name to switch project.
  • Pinned, not recent, with a pin icon: projects, boards and agents in one list the person orders, each shown by its avatar. Inside a project, "Projects" is not highlighted; a pinned project is.
  • Tools grouped, most-used first: Work · Agents at work · Files and code · Team · Settings. Same on mobile.
  • Runs ≠ Automation. Runs is every run; Automation is the runs the system starts itself, with their controls.
  • Backlog is a view inside Tasks — settled with the Tasks board.
  • No repository on this screen; one site per project, shown as a fact.
  • Mobile project details are a full screen: facts first, tools below, no tabs.
  • No topic tags on rows, and no structured items inside conversations for now.
  • Private: each member sees only their own conversations (adr-0041, adr-0077).

Open — answer by number

  1. None on this screen. Undecided elsewhere: whether there is ever one organisation-wide agent — not part of this design.

New features this screen brings

  • Project lead — a person, shown only; no rights of its own.
  • Stop all for one project — over the existing project run stop; project admins.
  • First agent added becomes the default.
  • Project conversations — chats placed in the project.
  • Pins — kept in hq so they follow the person across devices.
  • Default avatars for projects (initial on the project colour) and boards (board mark on a colour); agents keep their own. Room for real project and board avatars later.
