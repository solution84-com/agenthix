Where we are

Agreed

  • One timeline: Now, then Later (each routine only by its next run); Routines and Rules as buttons between them.
  • Routines view: switch, schedule, who it runs for, next run; New routine; opening one edits it.
  • Rules view: the agents' switch, the limits, then "Columns that start work automatically" (only those on, linking to each board; switched on the board).
  • Archive finished tasks moves to the project's Settings.
  • Pause stops new automated starts only; running work carries on (Stop all ends it).
  • Limits: the turn limit (only runs no person started) is edited in Rules; the run time limit (every run, conversations included) is edited in the project's Settings and shown read-only in Rules.
  • Automation is a tool beside the conversation, in the Agents at work group, with Run all and Stop all.
  • Runs ≠ Automation: Runs is every run; Automation is what the system starts itself, and its controls.
  • The layouts: narrow shows a summary, wide shows everything.
