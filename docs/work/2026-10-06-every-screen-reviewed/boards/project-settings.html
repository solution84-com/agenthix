A project's Settings

The last tool in a project's tools panel. Many of its settings now live elsewhere — people, agents and their permissions — so this is what is left, who may change each part, and what everyone else sees.

Agreed

  • Members and Viewers see Settings as facts to read, with who can change them (p2) (owner, 2026-10-09)
  • The key stays locked once a task exists — task numbers, links and agents' notes are made from it. Locked, it is shown as plain text with the reason, never as a field that looks editable; before the first task it is a field (owner, 2026-10-09)
  • Deleting a project stays the organisation admins'. A project admin sees one line saying so; an organisation admin sees Delete with its confirm; Members and Viewers see nothing about it (owner, 2026-10-09)
  • The default agent is set here, under Agents, from the project's own agents, by its admins: new conversations here start with it (owner, 2026-10-09)
  • Where it runs is shown read only. Moving a project to another site is a later item, not blocking the first release (owner, 2026-10-09)
  • Each part saves on its own as it is changed — a choice at once, a text field on leaving it — with a short "Saved" beside it; no Save buttons (owner, 2026-10-09)
