# Design boards

The boards this unit's screens were designed and agreed on, as they stood when the unit closed on
2026-10-12. Each is a standalone page: open it in a browser (each has a light and dark switch). They are a record
of what was built against, not a description of hq today — the [spec](../spec/README.md) holds the design in words,
and later changes are not reflected here.

The later boards show each feature as it was (**Before**), as agreed (**After**) and **Why**, with the questions the
owner answered by number under **Agreed**. Earlier boards were edited in place as the design moved, so each shows
only its final agreed state.
