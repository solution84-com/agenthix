Where we are

Agreed

  • Same shell as Conversations: navigation, breadcrumb, right panel with facts and grouped tools.
  • The conversation replaces the list; back is the breadcrumb (desktop) or ‹ (mobile).
  • One agent per conversation, fixed — no picker in the composer. Several agents in one conversation: not now.
  • Rename by editing the title in place. No ⋯ menu: no pinning conversations (most end in one sitting), no close (the breadcrumb leaves).
  • Tools beside the conversation: one tool open at a time in the panel, updating live; ‹ Tools goes back; the panel never switches by itself. No "Open full … view" — Tool only covers it; tool pages stay for outside links. Tool only with no tool open shows the panel as it is (facts and tools list).
  • One layout control in the bar above both panes (with the breadcrumb), present in every layout; four layouts: Conversation (tools hidden), Side by side (default), Tool focus, Tool only (conversation hidden). Remembered per person. No dragging.
  • The right panel is one surface: project facts and tools as sections of the same view, no cards, no padding around them.
  • Your messages right-aligned in a light block, no avatar; the agent's replies left-aligned under its name.
  • The message box: white with a border; the model picker kept as a normal control; voice; an accent send button.
  • The conversation and the list sit on white; only the navigation is grey.
  • Reading surface: 15px / 24px, about 720px wide, centred.
  • What chat does today stays: compact tool calls, approvals answered in place, voice, copy. No structured items.
