Tool — Boards

A board is a workflow: a lasting set of columns that a kind of work moves through — the project's tasks, its bugs, its launch content. It keeps its name and its backlog for as long as the project uses it. A sprint board adds sprints: time boxes that tasks are planned into, finished one after another, while the board stays. Every project starts with one board, so there is always somewhere for work to go.

The model — proposed

Project Tasks — the default board

BacklogTo doIn progressDone
  • Made with every project; cannot be deleted or renamed
  • Its columns are the task's own states, and cannot be changed
  • Every task lands here unless it is put on another board
  • No sprints, no columns that start work by themselves

A workflow board

BacklogReportedFixingFixed
  • Any columns, each mapping to To do, In progress or Done
  • Backlog is its first column: tasks on the board, not started
  • A task moves to another board from its ⋯, landing in that board's Backlog
  • A column may start work when a task enters it
  • Lasts until archived; no completing, no "Bugs 2"

A sprint board

BacklogTo doIn progressDone
  • A workflow board with sprints: Sprint 12, 6–20 Oct — renamable
  • Backlog holds what is in no sprint; dragging a task out of it puts it in the current sprint
  • Finishing a sprint asks where unfinished tasks go — no default
  • Finish sprint: done tasks stay recorded in it
  • Past sprints stay readable

Agreed

  • The Boards design is agreed (owner, 2026-10-08)
  • Boards is the next design pass (owner, 2026-10-07)
  • A board opens inside the tool, like everything else (owner, 2026-10-08)
  • A board keeps its own backlog: a board is a workflow, and its backlog organises its work (owner, 2026-10-08)
  • A board is a workflow with an identity, not a life cycle; sprints are a kind of board — a sprint board — that tasks are assigned into (owner, 2026-10-08)
  • Every project has a default board, To do · In progress · Done mapping to the task's states, with no workflow of its own; it cannot be deleted. New (owner, 2026-10-08)
  • The default board is Project Tasks and cannot be renamed, so it is never mistaken for another; every task lands on it unless put on another board (owner, 2026-10-08)
  • Backlog is a column — the first on every board. A task moves between boards from its ⋯, landing in the other board's Backlog (owner, 2026-10-08)
  • Finishing a sprint: done tasks stay recorded in it; the next sprint runs the same length (owner, 2026-10-08)
  • Finish sprint and Rename sprint sit in the sprint's box; Run all is not on the board — it stays the place's (owner, 2026-10-08)
  • Decision record written: adr-0097, a board is a lasting workflow (owner, 2026-10-08)
  • A board's columns are called columns everywhere, in the product and in the code, not "stages": three different things stay three words — a board's column, a task's state (To do, In progress, Done), a run's run state (owner, 2026-10-08)
  • A sprint can be renamed; its number stays as a small marker beside the name (owner, 2026-10-08)
  • Where unfinished tasks go is asked when a sprint is finished — next sprint or Backlog — and must be answered; there is no default, for a person or an agent (owner, 2026-10-08)
  • A Backlog shows its own board's tasks always; other boards' backlogs only when chosen with a filter, under their own heading. Tasks › Backlog starts on Project Tasks with the same filter (owner, 2026-10-08)
