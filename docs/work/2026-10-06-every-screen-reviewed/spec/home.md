# Home

Part of the unit's design spec: see [the index](README.md).

## Home

Home is **personal**. It answers three questions, in order.

1. **Can I start talking now?** A greeting ("Good afternoon, Avery — What would you like to work on?") and the
   message box at the centre, focused when Home opens. It starts a conversation in Chat with the agent the person
   used last.
2. **Is anything waiting on me?** One line of buttons under the message box: "● N notifications need you"
   (opens Notifications), "● N agents at work" (opens Runs), "N coming up today" (opens Automation). These count
   only what is the person's own or acts on their behalf.
3. **Where was I?** **Jump back in:** the person's most recent conversations from every project and from Chat, each
   naming its place.

Nothing else is on Home. Today's dashboard cards leave it. The organisation-wide ones — totals, cost, financial,
top agents, run overview — go to the Organisation page's Today and each agent's usage ([Organisation](organisation.md), [Agents](agents.md)); a site's load is on its card and page ([Execution Sites](sites.md)). Recent projects are replaced by pins.
**Mobile:** the same order, with the message box at the bottom, within reach of a thumb.
