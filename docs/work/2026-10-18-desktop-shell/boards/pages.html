How to read this

Each section is one page of hq as the agreed spec (2026-10-17) draws it. A short Today line says what it is now, the mockup shows the page afterwards, and the open questions that page raises sit right under it. A Q1 badge and a  dashed outline  in a mockup mark the part a question is about. Click an option to note a leaning; answer in the terminal by number. Every question is also listed together under All open questions.

The ground rule (owner, 2026-10-18)

Approved: the layout change and a project's tools as tabs, and nothing else. Tabs only put the existing content inside tabs. No page's content changes, no server API changes, and no component changes, above all the conversation interface (the thread, the message box, the pickers, the work bar), which stays exactly as built. If something can't be done without a change, it's raised with the owner first, one item at a time, with why it's unavoidable. Never folded into the build.

Questions below that would need such a change say so in a needs your approval tag. Their recommendations are now the option that changes nothing.

0 · The frame on every page

Three columns everywhere: the navigation on the left, the canvas for work in the middle, and the dock on the right with the one open conversation. Only the canvas changes as you move around. The dock changes only when you change it.

Navigation
Home, Chat, Projects, Agents, Tasks, pinned, Settings
Canvas
Whatever page you're on, at full width. Changes on every click.
Dock
One conversation, kept in the address as ?c=. Stays through every page change.
What it takes (no question, just scope). The pages' content doesn't change. What moves is the frame around it. Today each page carries its own copy of the frame: Home is "frame + Home", a project is "frame + project". Going from one to the other swaps the whole pair, so the old frame is removed and a new, identical one is built. You don't notice, because the frame holds nothing live. A dock in that frame would hold a live conversation: its connection, a reply still streaming in, how far you'd scrolled, a half-written message. Every click would remove it and build it again, so you'd lose the scroll and the draft, and it would reconnect and flicker. So the frame moves out of the pages to one copy above them all, and only the content inside it swaps. This is a layout change only. No page's content changes: every page looks and works exactly as it does now. The pages needn't be edited at all: the piece each page wraps itself in today keeps its name, and instead of drawing a frame it only passes the page's breadcrumbs and bar buttons up to the one frame. The change is in the frame and the app's root; the only page-level screens that change are the places', and those change anyway for the tabs.

</Frame>
