  • Minimised leaves no grey strip: the chat's bar, white-tinted, with its menu and queue.

App layout: the left panel

future state · iterating

The main navigation never goes away. A slim rail on the left always holds the app's places and your pinned projects; a project's own menu opens beside it, not instead of it.

Today: in a project, the main menu is gone

Opening a project replaces the left panel with the project's menu. The only way to Home, Tasks or another project is the "‹" at the top, which looks like Back.

Today: that "‹" opens a "Go to" pop-up

It isn't Back: it slides the main menu over the project's, with a ✕, and dims the page. People have expected Back here more than once.
