#WhatWhy
1Filters: kind, agent, place, tag, and search. Each menu has the same values as its badge: Fact, Rule; Every agent, Kernel, Scout. Kernel shows the memories marked "Kernel"; place works the same way.A filter means exactly what the badge says, so the list never shows a row that seems not to match.
2Badges on the line under the title: the kind (Fact or Rule), then which agents ("Kernel" or "Every agent"), then where ("Your space" or "Everywhere").Each badge answers one question, in the words of the switch that changes it (owner, 12 Nov).
3Then tags and the date on the same line.One line for where it holds and how to find it; the title stays alone above.
—No pictures, no colour. Who wrote it, and whether it was promoted, is in the opened memory (board 4).The row answers what decides recall, and nothing else.
—Kind first, as its own badge: Fact or Rule (outlined dashed, so it reads apart from where it holds). Also a filter.A Rule is weighted in recall and replaces its older self; a Fact is joined. The two behaviours are the two kinds (owner, 12 Nov).

On a phone: the same rows; the filters fold into one Filter button.

#WhatWhy
1, 2The scope as two switches: which agents (only this one, or every agent) and where (only this place, or everywhere). Promoting is flipping one; it can be flipped back.Two plain questions instead of four scope names. The four combinations fall out of them, and nothing else needs explaining.
3What it says, read only: title, text, kind, tags. No editing (owner, 12 Nov).The memory is the agent's own, in its words. To correct it, tell the agent, or forget it.

#WhatWhy
1Only when you asked ("remember…", or a correction): one line, styled as a system message, "Kernel remembered this"; one for each memory. A memory the agent saves on its own shows nothing here; it is on the memory screen (owner, 12 Nov, following Claude and ChatGPT).The conversation is for the conversation. Saving a memory is a side effect worth noticing, not reading (owner, 12 Nov).
2One button: Show.The only thing to do from here is look, and from there correct, promote or forget.
3Show opens the memory in a dialog, centred over everything: the two switches, the words (read only), Forget, and a link to all your memory. —In a call: say "for every agent" in the same sentence, or press Show in the transcript afterwards.You can't press while speaking.

13 · To settle

Recommended defaults: taken unless you say otherwise

#DefaultBoard
1Every memory shows two badges on the line under its title: which agents (Kernel / Every agent) and where (Shop / Everywhere), the same words as the switches; then tags and date. No pictures, no colour.2
2Filters: agent (Every agent, Kernel, Scout), place, tag, and search; each matches its badge exactly. No kind.2
3A memory opens in the same centred dialog everywhere: the memory screen, an agent's page, Show in a conversation. The scope is two switches. Agreed 12 Nov.4
4Decided 12 Nov: no adding or editing. A memory can be promoted or forgotten, nothing else; no Pin.5
5"Forget", never "Delete" or "Remove", matching the agent's own word. Decided 12 Nov.4
6An agent's page shows its own memory, then, folded, what every agent knows. Agreed 12 Nov.8
