Sprints are optional: time boxes of the same length, one after another, that you plan tasks into. Start sprints asks how long each is and when the first begins.7
1The current sprint
Its number, dates and days left; See Sprint 4 on a board › opens the board filtered to Sprint 4, grouped however you last grouped it.		D8, D13: a sprint is the project’s time box; a sprint board is any board filtered to it (B5).
2How it is going, by task state
One bar by task state across every type, with its counts in words; Done always means done. What runs now is one line linking to the Workroom, not a count here; in the list each task’s agent is ringed with its execution state (D18), with no state chip.		D2: task state and execution state kept apart; P1; D18.
3Finish sprint…
A sprint ends only when someone (or an agent’s finish_sprint) finishes it; past its last day the page says “ended 2 days ago” beside it. Asks where the unfinished go; finishes at once when all are done. ⋯ holds Rename.		B6, brought across; N7.
4Upcoming sprints
The next sprints in the series, each with its dates and how many tasks are planned in it; Plan it › opens planning. The page’s one filled button plans the next sprint; on the phone, Plan Sprint 5 is the first item in the top bar’s ⋯.		Planning takes tasks from Backlog or To do into a sprint. “Only see upcoming sprints”.
5Past sprints, out of the way
One quiet link at the page’s foot, Past sprints (3) ›, opens them as a simple list (dates, what was done, what moved on), newest first; each opens its tasks.		B6; the spec keeps them.
6One series, one length
The series’ length and start day are set here, once for the project: Sprint length… (on the phone, in the top bar’s ⋯, with the length said in the page’s first line).		D13: one series per project, one cadence for every type.
7No sprints yet
Says what sprints are and how to start; Start sprints asks how long each is and when the first begins.		The empty-list rule; sprints are optional.
