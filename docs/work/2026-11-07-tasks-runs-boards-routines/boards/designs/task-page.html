#What each number is
1Type, first in the header
Changing it keeps the state: the task lands on the new type’s default column for that state (here Feature request → Accepted). Epic is greyed, with why, on a task that has runs. D10, D12.
2The column, by name only
The menu lists the type’s columns, nothing else; the task state behind them never shows here (it is defined in Settings › Task types). D2, D5, D10.
3Sprint, by name only
One sprint of the project’s series, or none. Its dates show only in Sprints. D8, D13.
4Order is never shown as a number
No Rank field. The place in the project’s order changes by dragging on any board, or with ⋯ › Move to top / Move to bottom. D14.
5The project’s custom fields
One row per single-select field; — means none. Views only, never the state. D4.
6The agent, its ring, and the run in words
The agent’s avatar with the run’s ring (D18) and, unlike a list, the words beside it: Not started, Running · 1 min, Needs your okay. The filled button follows: Run ▾, Stop, Review; on the phone that action leads the ⋯ menu (Run now, Run at…). D6, D18.

2Create task, top right
