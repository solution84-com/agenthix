C3 · "Make this a skill": proposing

Agents propose, people accept (R6). A person asks an agent to turn a way of working into a skill. The agent writes it with the built-in skill-creator and proposes it with the propose_skill tool. A card in the conversation shows the draft until someone reviews it. A draft reaches no agent.

1The tool

propose_skill, a platform tool on hq's side of the channel, gated like the other platform tools. Arguments: name, description, body, files (bounded as staging is), why, for (organisation, project or mine), and optionally edits (the identity of the skill it changes).

2What hq does

It checks the draft against the Agent Skills specification (R8) and keeps it as a proposal: the content by fingerprint, who proposed it (agent, person, conversation) and for which level. It writes nothing into any place's files and gives it to no agent.

3Who reviews (D27)

The maintainers of the level it aims at. organisation: administrators and Library maintainers, in the Library (R1). project: the project's administrators. mine: the person, in the card itself. The card names them, and the person can aim it elsewhere. If the person asking may already publish at that level, it is their draft instead (3b).

Why a proposal and not a file: a skill is standing instructions for everyone who uses that agent there. A person should read it first. The place's default already keeps agent-written files off (D13); the tool gives agents the right path, and the built-in skill-creator tells them to use it.

2 · A skill for yourself: accepted in the card

Before

Nothing. A person's own skills exist only as files in Your space.

After

When the skill is for the person (for: mine), they are the reviewer, so the card offers Add to my skills, Edit first and Not now. Accepting writes it into Your space's skills, switched on, and it follows them (D15).

3 · Proposing a change to an existing skill

Before

An agent that finds a skill wrong can only work around it.

After

With edits set, the card shows the difference from the current version. Accepting saves a new version. For a skill another publisher signed, accepting makes the organisation's own copy, based on the original (D18, D19).
