The records

In hq

1Asset

One per identity per organisation. Key: (kind, publisher, name), unique without a nullable column (closes T10). Fields: kind (skill, agent, board, team), publisher (verified signer's recorded name, unsigned, or the organisation for made here; C1), name, currentVersionId (the pin, V1), givenToAll (L2), builtIn + switchedOff (L1a, D6), setAsideById (D18: the copy that replaced it), suitedTo hint.

2AssetVersion

Every installed or published version. Fields: version (SemVer, D30), digest → PackageContent, signer and source (D8), basedOn lines (D19; only lines hq wrote are verified, M5), licence, note, by and when, withdrawn flag for Agenthix's (D30). Never deleted while current or in history (V6).

3PackageContent (existing)

Immutable, by digest (packageDigestInput, package.json included, H1). Shared by every row that names the digest. The sweep skips any digest an AssetVersion, Draft, Proposal, PlaceSkillVersion or a run's record still names (V6, D26).

4AssetGrant

Which agents have an asset when not every agent (L3, D23). Key: (assetId, agentId). Templates create grants for the agent made from them.

5Draft

One per asset, shared (D25, EQ4). Points at a draft content digest and keeps its own revision list (author or proposing run per change, H5). Publish names the revision the publisher saw and is refused if a newer one exists (H5). For a place skill, the draft is keyed by place + path instead (FV1).

6Proposal

From propose_skill, or a member's New skill. Aim (organisation, project, person), the asset it edits (optional), content digest, agent, person (from the run's on-behalf-of record, H5), conversation or run, state (open, accepted, accepted with changes, rejected + note). One open proposal per name per place (CQ12).

7TrustedPublisher

Keyless: issuer + exact certificate identity + repository + ref constraint (H2), or a public key. The recorded display name (D9). Agenthix's is built in and can't be removed (P1).

8LibraryMaintainer

One row per member (D28): the organisation role. Dropped when the member leaves; history keeps the name.

9PlaceSkill · PlaceSkillVersion

A skill found in a place's files, keyed by (place, path), with its switch (on, off, by fingerprint, D13, H3), source group (place, one agent, workspace n), and set-aside reason. Its versions: number, digest, published by (FV2), so roll back works (FV3). Changed in files, not published is a reported fingerprint that matches no version (FV4).

10Settings

On the organisation: unsigned allowed (P2), who installs from outside (P3), skills found in files default (C1, shipped off by default), personal skills outside Your space (D15). On a place: its stricter default (C1b).

Retention

  • Asset versions: kept while current or in the history (V6). Removing an asset keeps its history (the old R5), so it can be restored.
  • Content a run used: as long as the run's own record (D26, CQ6). A person's skill content goes when the person is removed, leaving identity and fingerprint (M6).
  • Drafts: until published or discarded.
  • Proposals: accepted ones stay with the asset's history; rejected ones are removed after 90 days (RQ5).
