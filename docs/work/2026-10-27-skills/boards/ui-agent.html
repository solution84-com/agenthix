A1 · An agent's page: everything it will see

An agent's Skills section lists every skill the agent will use, by level, with anything set aside and why, and what the list costs per request (spec part 6, D21, R9). Administrators add and remove; everyone else reads (D23). Shown for the agent Ada in Fernhill.

Today, numbered

  1. One level only. The manage page (/admin/agents/ada, ManageEditors.tsx) summarises Skills as names joined by " · ", from Ada's own package. Skills installed for the organisation, built-ins and the places' files aren't shown (T4).
  2. Add offers library skills only. The editor (ui/src/agents/tabs/SkillsTab.tsx) picks from the built-in library (scope PLATFORM), so one agent can't have a skill made here.
  3. A copy each time. Add copies the skill into Ada's package; Update appears when the library moved on (T2).
  4. Members see less. The member page (/agents/ada) shows only Your skills, names from their own space.
  5. No sense of cost. Every skill listed adds to every request; nothing says how much (T3).

People's own skills

When someone talks to Ada, their own switched-on skills join that conversation (D15). They're each person's, so they aren't listed here.

  1. Grouped by why Ada has it, in the clash order (D16): built in, every agent has, Ada has, then each place Ada works in. hq builds the list from the installed set, the grants and each place's switched-on fingerprints, the same inputs it resolves for a run (spec part 5).
  2. Built-ins show on. Switching one off is for every agent, in the Library (R7: no per-agent exceptions).
  3. Every agent has these links to the Library, where it's taken away for all agents.
  4. Add a skill opens a picker over the Library's installed skills and the offered shelf; an offered one is installed through the install check (U4) and added to Ada in one step. Remove from Ada takes it from Ada only.
  5. Places are collapsed to a line each, with counts; Open goes to that place's Skills page (P1), where its administrator switches them.
  6. Cost: the estimate adds each listed skill's name and description, as the runtimes list them, for Ada's own levels, plus the skills of the place a run would be in (PQ10).
