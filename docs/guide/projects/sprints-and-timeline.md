A **sprint** is a numbered stretch of time that belongs to the project, not to a board. A project has one series of
sprints, each the same length, one after another, and every task type shares it. A task is in at most one sprint, and
putting it in or taking it out never changes its column or state, with one exception: adding a **Backlog** task to a
sprint moves it to **To do**.

## Sprints

Open **Sprints** in a project. Until you start them it says **No sprints yet**.

1. Select **Start sprints**.
2. Choose how long **Each sprint lasts** and when **The first begins**, and confirm.

The page then shows, from the top:

- **The current sprint**, with its dates, how many days are left, how its tasks spread across the task states, and
  anything **At work now**. Its **Goal** can be edited (**Edit the goal**).
- **Upcoming** sprints, each saying how many tasks are planned in it, or **Nothing planned yet**. The next two can be
  planned ahead.
- **Past sprints**, each in one line such as "9 done · 2 moved to Sprint 5".

A sprint's menu has **Rename…**, which keeps its number, and **Sprint length…**, which changes the length of the sprints
after the current one. The current sprint keeps its dates.

### Plan a sprint

Select **Plan sprint** on a sprint. The page shows **Backlog and To do** beside the sprint, as two lists.

- Drag a task from the left to the sprint to plan it in, within the sprint to order it, or back to take it out. Every
  task's **⋯** does the same. A Backlog task dropped into the sprint moves to **To do**.
- Search, filter by **Type** or **Epic**, or turn on **Group by epic** to find what you need.
- Each move is saved as you make it, so there is nothing to save. **Done planning** goes back to **Sprints**.

On a phone, one list shows at a time. You can also add tasks to a sprint from a task's page, from a card's **Sprint**
menu on a board, or by filtering a board to a sprint.

### Finish a sprint

A sprint is finished only when someone finishes it. If its date passes, it stays the current sprint and shows as
overdue.

1. Select **Finish sprint…**.
2. The dialog says how many tasks are done, which stay recorded in the sprint, and asks where the tasks not done go:
   **the next sprint**, or **No sprint**, to plan them again. Nothing is chosen for you. Their task state and column stay
   as they are.
3. Select **Finish sprint**. The next sprint becomes the current one.

## The timeline

Open **Timeline** to see tasks against dates.

- **Week**, **Month** and **Quarter** set the scale.
- **‹**, **Today** and **›** move through time.
- **Show** chooses **Tasks**, **Epics** or **Milestones**.
- Each task type has its own lane. **Types** chooses which appear.
- A task's bar runs from its plan **Start** to its **Finish**. Drag the bar to move it, or an end to change it. That changes
  only the plan: it never starts or stops a run.
- **▶** marks a task's own start time, the time **Run at…** set.
- An **Epic** groups tasks and spans theirs. A milestone (⚑) is a dated goal that epics belong to. An agent makes one when
  you ask in a conversation, and an epic's **Milestone** field then offers it.

Select a bar to open its task. **‹ Timeline** returns you to where you were.
