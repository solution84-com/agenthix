These pages use the agents of your organisation's **HQ**, your organisation's home in Agenthix; see
[How Agenthix works](../getting-started/how-agenthix-works.md). An agent is defined once for the whole organisation,
then given its own instructions, its own permissions, and a place in the projects where it works.

1. [Create an agent](create-an-agent.md): name it, choose its model, and put it to work.
2. [Instructions and memory](instructions-and-memory.md): what an agent is told, and what it remembers about you.
3. [Permissions and approvals](permissions.md): what an agent may do alone, and when it must ask.
4. [The Library](library.md): ready-made agents, boards, skills and teams to start from.

Only an organisation administrator creates agents and changes their instructions and permissions. Everyone else
can talk to them, give them tasks, and set their own memory and permissions for their own conversations.

## An agent's own page

Select **Agents** in the side bar, then an agent, to open its page. Like a project, its sections are in the side bar: **Overview**,
**Conversations** (yours with this agent), **Now**, **Projects**, **Runs**, **Usage**, **Your instructions**, **Memory**
and **Your settings**. See
[Inside a project](../projects/projects.md#inside-a-project).
