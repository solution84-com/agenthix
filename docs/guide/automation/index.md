These pages use the projects and agents of your organisation's **HQ**, its home in Agenthix; see
[How Agenthix works](../getting-started/how-agenthix-works.md).

Agents never start tasks on their own. A task runs only when a person or an agent starts it: see
[Starting work](../projects/starting-work.md). The one thing that begins on its own is a routine you set up.

1. [Routines](routines.md): an agent does the same job again and again, on a schedule.
2. [Limits, and stopping everything](limits-and-stopping.md): how far an agent may start work, how long a run may last, and
   how to stop it.
