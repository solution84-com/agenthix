These pages use the projects and agents of your organisation's **HQ**, its home in Agenthix; see
[How Agenthix works](../getting-started/how-agenthix-works.md). Until you turn automation on, agents work only when
a person presses **Run** or starts a conversation.

1. [Turn on automation](turn-on-automation.md): let a project start queued tasks by itself.
2. [Routines](routines.md): create a task again and again, on a schedule.
3. [Limits, and stopping everything](limits-and-stopping.md): how far automation may go, and how to stop it.

Agents never start work on their own authority. Everything here is a setting that a person turns on, and each
setting can only be made stricter below the organisation.
