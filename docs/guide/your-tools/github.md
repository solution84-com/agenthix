Agenthix reaches GitHub through a **GitHub App** that an administrator of your **HQ**, your organisation's home in
Agenthix, registers once. Agents never hold a GitHub token: pushing, pulling and opening a pull request are
workflows that a person approves, and each run gets a token that lasts only for that run.

- [Connect GitHub](../workflows/connect-github.md): register the App, install it, allow accounts, and connect a
  workspace to a repository.
- [A client's GitHub organisation](../workflows/client-github-organisation.md): send a client a link to install it.
- [Back a project's files up](../projects/files-and-previews.md#back-it-up-to-github): a private repository holding
  the project's files.
- [Workflows](../workflows/workflows.md): approve what runs, and follow it.
